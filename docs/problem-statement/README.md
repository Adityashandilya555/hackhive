Honeywell text (`AGENTS.md`); the Honeywell text only fills gaps.

`~/HACKHIVE/...` in them point at Adi's local workspace, not this repo.

**cropped to the slide** so other participants' names and photos aren't published; the slide
content is untouched. Slide 5 exists only as these captures.
